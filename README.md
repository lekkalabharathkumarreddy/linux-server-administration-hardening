# Linux Server Administration & Hardening

## Project Overview

This project demonstrates Linux server administration and security hardening using Ubuntu Linux.

The project covers system administration, user management, file permissions, SSH hardening, firewall configuration, service management, logging, monitoring, and security auditing.

## Operating System

- Ubuntu Linux

## Tools & Technologies

- Ubuntu Linux
- Bash
- OpenSSH
- UFW Firewall
- systemd
- APT
- Git
- GitHub

## Project Objectives

- Secure Ubuntu Linux environment
- Implement user and group management
- Configure file and directory permissions
- Harden SSH access
- Configure UFW firewall
- Manage Linux services
- Monitor system logs
- Perform security verification

## Implementation

### 1. System Preparation
- Verified Ubuntu version
- Updated system packages
- Removed unnecessary packages

### 2. User Administration
- Created `sysadmin` user
- Added user to sudo group
- Verified administrative privileges

### 3. File Security
- Created secure directory
- Configured ownership using `chown`
- Configured permissions using `chmod`

### 4. SSH Hardening
- Installed OpenSSH
- Disabled root SSH login
- Generated ED25519 SSH key
- Enabled public-key authentication
- Disabled password authentication

### 5. Firewall Hardening
- Configured UFW
- Denied incoming traffic by default
- Allowed outgoing traffic
- Allowed SSH access

### 6. Service Management
- Checked SSH service
- Started and restarted services
- Verified service status

### 7. Logging & Monitoring
- Reviewed system logs
- Reviewed SSH logs
- Checked disk usage
- Checked memory usage
- Checked system uptime

### 8. Security Audit
- Verified SSH configuration
- Verified firewall status
- Verified user privileges
- Verified file permissions
- Checked listening ports
